# Grill With Docs

This skill combines **grilling** (a relentless frontier interview) with **domain modeling** (capturing terminology in `GLOSSARY.md` and decisions in `docs/adr/`).

Follow both procedures in tandem:
1. Conduct the structured interview from [grilling](../grilling/SKILL.md).
2. Apply the documentation discipline from [domain-modeling](../domain-modeling/SKILL.md) to record terms and ADRs inline as choices crystallize.
